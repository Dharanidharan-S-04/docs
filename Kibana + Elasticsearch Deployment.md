## Step 1: Clone the infra repo
```bash
git clone -b https://github.com/tf-nira/k8s-infra.git
cd k8s-infra/logging
```

## Step 2: Uninstall existing Elasticsearch release
```bash
helm uninstall elasticsearch -n cattle-logging-system
```

## Step 3: Edit `install.sh`
```bash
vi install.sh
```

Replace this line:
```bash
helm -n $NS install elasticsearch tf-nira/elasticsearch -f es_values.yaml --version 17.9.25 --wait
```

With:
```bash
helm -n $NS install elasticsearch tf-nira/elasticsearch -f es_values.yaml \
  --set image.repository=technoforte2023/elasticsearch \
  --set image.tag=production \
  --set sysctlImage.repository=technoforte2023/bitnami-shell \
  --set sysctlImage.tag=dev \
  --set kibana.image.repository=technoforte2023/kibana \
  --set kibana.image.tag=dev \
  --version 17.9.25 --wait
```

Comment out all other `helm install` commands in the script (leave only the Elasticsearch install active).

## Step 4: Edit `es_values.yaml`
```bash
vi es_values.yaml
```

After the `kibanaEnabled: true` line, add the following block. **Indentation must start aligned with `global`:**

```yaml
security:
  enabled: true
  elasticPassword: "elastic@123"
  tls:
    autoGenerated: true
    restEncryption: true
kibana:
  persistence:
    enabled: false
  elasticsearch:
    security:
      auth:
        enabled: true
        createSystemUser: false                       # chart creates 'kibana_system' user for you
        kibanaUsername: elastic
        kibanaPassword: "elastic@123"                 # password for kibana_system user
        elasticsearchPasswordSecret: elasticsearch    # name of the ES secret holding the 'elastic' password
      tls:
        enabled: true                 # ES REST API is now HTTPS
        existingSecret: elasticsearch-master-crt   # secret with the autogenerated CA/cert (chart-release-name + "-master-crt")
        usePemCerts: true
        verificationMode: certificate  # or "none" if you don't want to verify (not recommended)
```

Then **comment out** the old/duplicate 3-line block that appears later in the file:
```yaml
#  kibana:
#    persistence:
#    enabled: false
```

## Step 5: Run the install script
```bash
./install.sh
```

## Step 6: Wait for pods
Wait until the `elasticsearch-coordinating` pods come up. Once those are ready, the Kibana pods will follow and come up automatically.
