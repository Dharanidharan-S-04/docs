Step-1: Generate Auth Token using below Swagger Link
https://api-internal.dev1.mosip.net/v1/authmanager/swagger-ui/index.html?configUrl=/v1/authmanager/v3/api-docs/swagger-config#/authmanager/getAllAuthTokens


Use your credentials along with below client id 
   mosip-pms-client

use the client secret: mosip-pms-client-secret

Now send the POST request to get a auth token.

NOTE: Check that User must have AUTH_PARTNER & PARTNER_ADMIN roles.

Step-2: Renewing the Misp License key using below Swagger Link
https://api-internal.dev1.mosip.net/v1/partnermanager/swagger-ui/index.html?configUrl=/v1/partnermanager/v3/api-docs/swagger-config#/misp-license-controller/regenarteLicenseKey


Update the misppartnerid which has been expired
